# README figure sources

The following figures are reproduced from **AgentWorld: Benchmarking Long-Horizon
Collaboration of Multi-agent LLMs**, Raphael Shu, Yusen Zhang, Young Min Cho,
Jin Mo Yang, Yuan Yuan, Wenliang Zheng, Sharath Chandra Guntuku, Lyle Ungar,
Zhou Yu, and Rui Zhang, 2026.

Source: [arXiv:2609.31590, version 1](https://arxiv.org/html/2609.31590v1).
The paper is released under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
These figure assets retain that license, separately from the repository's MPL-2.0 code license.

repository use. Dimensions and image pixels are unchanged; no crop, annotation,
or substantive modification was made. README captions are paraphrases, and each
image links to its full-resolution local copy.
