# Collectable Resources in AgentWorld

This document provides a comprehensive guide to all the resources you can collect in AgentWorld, including the tools required, skill levels needed, and items obtained.

## Overview

AgentWorld features **4 main types of collectable resources** distributed across the game world:
- **803 trees** for lumberjacking
- **383 rocks** for mining  
- **106 fishing spots** for fishing
- **239 foraging spots** for plant gathering

Each resource type requires specific tools and skills to harvest successfully.

## 🎮 Collection Mechanics

### Basic Requirements
- **Proximity**: Must be within 2 tiles of the resource to interact
- **Tool Requirements**: Each resource type requires the appropriate tool equipped (except foraging)
- **Skill Levels**: Higher level resources require higher skill levels to harvest
- **Experience Gain**: Successfully collecting resources grants experience in the relevant skill

### Advanced Mechanics
- **Difficulty System**: Each resource has a difficulty rating that affects success chance
- **Respawn Times**: Resources respawn after being depleted (varies by rarity)
- **Double Rewards**: Special weekend events can provide double rewards for mining
- **Achievement System**: First-time collection of certain resources grants achievements

### Resource Distribution
Resources are distributed across different biomes and regions:
- **Trees**: Found in forests, ice areas, and various biomes
- **Rocks**: Located in mountain areas, caves, and mineral-rich regions  
- **Fishing Spots**: Available near water bodies, coastal areas, and aquatic regions
- **Plants**: Scattered across fields, forests, and agricultural areas

## 🏆 Special Features

### Achievements
- **firstrock**: Awarded for first mining attempt (Coal, Copper, Tin, Nisoc, Beryl)
- **firstfish**: Awarded for first fishing attempt (Shrimp, Tuna)

### Quest Integration
- Some resources are tied to specific quests (e.g., Tutorial Snow Oak)
- Certain items may be required for quest completion

### Economic Value
- All collected items have market value and can be sold to NPCs
- Rarer materials (gems, bloodwood) typically have higher prices
- Raw fish can be cooked to increase value and provide food effects

## Tips for Efficient Resource Collection

1. **Start with Level 1 resources** to build up your skills
2. **Carry appropriate tools** for the resources you plan to collect
3. **Check respawn times** for rare resources to plan efficient routes
4. **Focus on achievements** for initial skill building
5. **Consider market prices** when deciding which resources to prioritize
6. **Weekend events** provide excellent opportunities for double mining rewards

## Resource Locations

Refer to the world map and region documentation for specific resource spawn locations. Resources are distributed based on biome type and regional characteristics, with rarer materials typically found in more dangerous or remote areas.
